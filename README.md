# Эмулятор процессора. Вариант 10

Эмулятор двухадресного процессора с архитектурой фон Неймана. Требуется Python 3.10 или новее, внешних зависимостей нет.

## Интерфейс в браузере

```powershell
python web_ui.py
```

Команда открывает окно браузера по адресу `http://127.0.0.1:8765`. Вставьте код, перетащите файл в редактор, выберите файл или один из примеров. Нажмите «Загрузить в ОЗУ», затем «Шаг» или «До HALT». Метки в панели ОЗУ помогают перейти к массивам и результатам. В трассе можно выбрать выполненную команду и посмотреть её регистры, флаги и запись в память. Панель ОЗУ показывает текущее содержимое.

Кнопка темы запоминает выбор в браузере. Локальный сервер ведёт один сеанс процессора. Для самостоятельного сеанса запустите второй экземпляр с другим `--port`. Ctrl+C завершает сервер.

## Запуск из консоли

```powershell
# Поиск максимума, вывод результата MAX_RESULT
python main.py programs/find_max.asm --result MAX_RESULT

# Свёртка, 3 слова результата
python main.py programs/convolution.asm --result RESULT --words 3

# Пошаговый режим (Enter - команда, q - выход)
python main.py programs/find_max.asm --step

# Только листинг машинного кода
python main.py programs/convolution.asm --listing

# Автотесты
python -m unittest discover -s tests -v
```

При обычном запуске эмулятор выводит состояние после каждой команды до `HALT`. В режиме `--step` Enter выполняет одну команду, `q` завершает сеанс. Параметр `--limit` задаёт максимальное число команд (по умолчанию 10 000). В качестве входа можно указать свой UTF-8-файл с ассемблерным текстом.

Спецификация, разбор требований и контрольные листинги приведены в [отчёте](docs/report.md).
